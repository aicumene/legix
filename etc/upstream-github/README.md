# gitoxide's GitHub configuration

gitoxide's workflows, Dependabot, funding and issue-template files as of v0.59.0, kept here for
reference. GitHub does not run them from this folder. leGix's own CI is `.github/workflows/ci.yml`.
They still use gitoxide's names (`gix`, `gix-*`): they were moved here after `etc/legix-rename.py`
ran. Treat them as a starting point when bringing parts of gitoxide's CI over.
